# 出す前の確認

`scripts/check.py` が誤りなしになり、ブラウザで見た目を確かめたあと、この表を上から確かめる。満たさない項目は直してからもう一度確かめる。

## 理解できるか

- [ ] 原理の 1 文が、まとめ欄にある。ページのどのセクションも、その 1 文のどこかを支えている
- [ ] 原理の掘り方（references/flow.md）の ①〜⑤ の答えが、それぞれどこかのセクションにある
- [ ] ユーザーがつまずいた現象への答えが、本文にはっきり書いてある
- [ ] 「なぜ」に答えるセクションが 1 つ以上あり、原理を使って答えている
- [ ] 見出しだけを上から読むと、話の筋が通る
- [ ] その技術を知らない人が、つまずく用語が残っていない（初出で意味を言っている）
- [ ] 例が最初から最後まで 1 つで通っている

## 正しいか

- [ ] 本文の事実は、出典に挙げた一次情報で確かめてある。確かめられなかったことは書いていない
- [ ] 出典から推論して書いた文は、根拠の仕組みが添えてある
- [ ] 単純化した図・数字に断りがある
- [ ] 時期で変わる数値に、時点か「変わることがある」がある
- [ ] 扱う範囲（どの方式・どの版か）を断ってある

## 文章

- [ ] セクション見出しが主張になっている（話題の名前だけの見出しがない）
- [ ] 問いの見出しのリードは、1 文目が答えになっている
- [ ] 文体が場所ごとのルール（references/writing.md）に合っている
- [ ] 1 文 60 字・1 段落 3 文を大きく超えるところがない
- [ ] 橋渡しが予告と問いで混ざっていて、同じ形が 3 回続いていない

## 見た目

- [ ] 幅 375px で、横にはみ出す要素がない。見出しが変な位置で折り返していない
- [ ] 暗い画面で、読めない字がない
- [ ] 図の字が、本文の列の幅で読める大きさになっている。箱から字がはみ出していない。図の下に大きな空白がない
- [ ] 表のような図（項目名と値を並べただけ）がない。図は場面か物の動きで見せている
- [ ] 図の赤は、その図で一番見てほしい 1 か所だけ
- [ ] 1 セクションの部品が図を含めて 3 つまで
- [ ] 同じ図の型・同じ部品が 2 セクション続いていない
