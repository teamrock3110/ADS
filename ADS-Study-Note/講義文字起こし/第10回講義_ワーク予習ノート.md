# 第10回講義 ワーク予習ノート（ストーリーライティング基礎練習）

第10回の全ワーク（①〜⑥）に共通する核心スキルを整理し、自分で練習できるドリル形式にまとめたもの。
講義内容の理解を深め、次に似たワークや卒業制作のプレゼンに取り組む際の土台にする。

## 1. 共通する核心スキル（講義の要点）

| # | スキル | 内容 |
|---|---|---|
| 1 | 説明ではなく体験させる | 「非効率・重要・課題・改善」などの抽象語は説明のサイン。裏にある具体的場面に戻す |
| 2 | 絵の材料の強さの順位 | ①自分が実際に見た場面 ＞ ②身近なたとえ ＞ ③数字・データ（土台として必要だが単独では心は動かない） |
| 3 | 絵を作る3つのコツ | (a) 超具体的にする（スローモーションで見る）/ (b) 心の声を入れる / (c) 例える（相手が知っているものに乗せる） |
| 4 | 結論と絵はセット | 絵は結論の代わりではなく「結論の根拠」。結論を先に言い切り、後ろに絵を置く |
| 5 | 興味の公式 | 興味＝知りたいこと − 今知っていること。差が「悪い差（混乱・不安）」か「いい差（続きが気になる）」かを区別する |
| 6 | いい差分の作り方 | (a) 問いかける（乱用注意） / (b) チラ見せする（結論は隠さず中身で小出し） / (c) 掛け金を上げる（失うものを具体化） |
| 7 | 弱さを見せる | 完璧な話ではなく、つまずき・半信半疑だった気持ちを自分から開示すると説得力が増す |
| 8 | プレゼンの構成 | 掴み → 結論 → なぜ（絵で見せる）→ どうやって → どうなるか（絵で見せる）→ お願い |
| 9 | 仕事のプレゼンの波 | 映画のように長く引っ張らない。YouTubeのように短すぎもしない。「小さく問いを開いて絵で閉じる」を数十秒〜1-2分で繰り返す |
| 10 | 引っ張りすぎ注意 | 期待させた分だけ中身を返す義務がある。煽るだけで中身がないと「釣り」になり信用を失う |

## 2. ワーク前セルフチェックリスト

書いた文章・話す内容を見直すときに、以下を自問する。

- [ ] 説明だけの文章になっていないか？（抽象語：非効率・重要・課題・改善などが出てきたら要注意）
- [ ] その場面をスローモーションで描けているか？（超具体的か）
- [ ] 心の声（そのときどう思ったか）が入っているか？
- [ ] 相手が知らないことを、相手が知っていることに例えられているか？
- [ ] 結論を最初に言い切っているか？（絵だけで結論が後回しになっていないか）
- [ ] 弱さ・つまずき・不安を1つでも含めているか？
- [ ] 引っ張った分（問い・チラ見せ）に見合う中身を返しているか？

## 3. 練習ドリル

### ドリル1: 抽象→具体変換（絵にする練習）

以下の抽象的な文を、3つのコツ（超具体的にする／心の声を入れる／例える）を使って書き換えてみる。

- 「このツールで業務効率が改善します」
- 「チームのコミュニケーションが活発になりました」
- （自分の卒業制作テーマに関連する一文を1つ自分で用意して書き換える）

### ドリル2: 興味の公式（いい差分づくり）

以下の一文を、「問いかける」「チラ見せする」「掛け金を上げる」のいずれかの型で書き換えてみる。

- 「うちの部署は残業が多いです」
- 「このツールを使えば作業時間が減ります」

### ドリル3: 弱さを見せる練習

自分が何かを始めたとき、最初に「これは無理かも」「半信半疑だった」と感じた経験を1つ書き出す。
→ 卒業制作のWhy（なぜこれを作りたいのか）を語るときにそのまま使える。

### ドリル4: 懸念点の先回り（ワーク④の応用）

卒業制作で作りたいツールを仮決めし、次の3点セットを作る。

1. ツールの概要（一言で）
2. 聞き手の頭に浮かぶ懸念点
3. その懸念点への自分なりの回答

### ドリル5: サブエージェントレビューの模擬

自分で書いた文章を音読し、聞き手の心の声を時系列で想像してみる（本番ではAIに社長役などをやらせて時系列の心の声を出力させる）。

## 4. 予習の進め方（おすすめステップ）

1. 上記セルフチェックリストで自分の書き方の癖を把握する
2. 卒業制作のテーマを仮決めする（ドリル4に直結）
3. ドリル1（抽象→具体変換）を3セット行う
4. ドリル3（弱さのエピソード）を1つ書き出す
5. 書いた文章を読み返し、結論が最初にあるか・絵と結論がセットになっているか確認する
