Task Worker データ設計

何を・どこに保存するか をチームに共有する

Task Worker とは

誰の・どんな問題を解決するか

誰が
放送系企業のコーポレートIT担当 = 放送局・メディア企業の社内IT業務を担う担当者
何してる
週4回の定例 = 各所関係者とのミーティング でアジェンダ = 議題リスト にタスク状況を書いて口頭報告
使っているもの
Jira = チーム全員のタスクを一元管理するツール
BEFORE — 今の課題

報告前の準備が毎回大変

  • メモ・報告文・参照リンクが複数のツールに散らばっている
  • Jira は全員分が混在していて「自分の担当分だけ」を見づらい
→
AFTER — Task Worker で解決

1画面でそのまま報告できる

  • タスク → メモ → 報告入力 → コピーが1画面で完結
  • 入力内容は自動保存。次に開いても残っている

コーポレートIT担当が定例で進捗を口頭報告するための補助ツール。

overlay.json を .gitignore にした理由
保存するたびに git diff に出てしまう / 報告文・メモなどの個人データをリポジトリに残さない。 STEP 2 で Neon に移行するときに捨てるファイルなので、Git 管理外が自然。
