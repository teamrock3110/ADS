## 既知の問題と対処法

### 1. 初回コンパイルが数分かかる / 固着する

**状況**: `○ Compiling / ...` で長時間止まることがある。

**疑い**: Tailwind CSS のスキャン範囲が広いと `.claude/` 配下の大量 MD ファイルを走査する。

**対処済み**: `app/globals.css` に `@source` 制限を追加（効果は未検証）。

```css
@source "../components";
@source "../lib";
@source "./";
```

**まだ固着する場合**:
```bash
rm -rf .next && npm run dev
```

### 2. ポート競合（古い next プロセス残存）

```bash
pkill -9 -f "workspace-it-kit.*next"
npm run dev
```

### 3. Neon 接続が固着の根本原因かどうか未確定

`DATABASE_URL` を一時的に無効化して再現するか確認する方法:

```bash
mv .env.local .env.local.bak   # 無効化
npm run dev                     # Neon なしで起動テスト
mv .env.local.bak .env.local   # 元に戻す
```

## アーキテクチャ早見表

```
app/
  api/overlay/route.ts   ← GET/PUT: DB or ファイル切り替え
  globals.css            ← Tailwind @source 制限あり

lib/
  db.ts                  ← Neon クライアント
  it/
    overlay-db.ts        ← Neon CRUD
    storage.ts           ← WorkspaceStorage 型・スキーマ

scripts/
  migrate.ts             ← テーブル作成（npm run db:migrate）

data/
  tasks.json             ← タスクマスタ
  task-links.json        ← 関連リンク（モック）
  overlay.json           ← DB 未設定時のフォールバック
```
